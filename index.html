À propos

Du code qui sert vos objectifs

Développeur passionné depuis plus de 5 ans, j'accompagne startups, agences et entreprises dans la création de produits numériques qui fonctionnent vraiment : une expérience fluide pour l'utilisateur, une base de code propre pour l'équipe et des performances au rendez-vous.

Côté web, je travaille avec l'écosystème MEARN — MongoDB, Express, Angular, React et Node.js — pour construire des plateformes robustes et évolutives. Côté mobile, je développe avec Flutter (Dart) et React Native pour livrer des applications iOS et Android à partir d'une base de code unique.

J'aime les interfaces soignées, les détails qui font la différence et le travail en équipe avec les designers et les porteurs de projet.
